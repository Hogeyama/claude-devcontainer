# 日本語IMEの確認

これは自動テストでは確認できません。普段使っているIMEと辞書で試します。

- エディタ内で「にほんごにゅうりょく」を入力し、未確定文字がキャレット位置に表示される。
- 変換候補がキャレットの近くに出る。スクロール、折り返し行、拡大率変更後も確認する。
- 確定前の左右移動、文節の変更、Escapeによる取り消しが普段どおり使える。
- 確定後に選択して再変換できる。普段のIME・辞書の候補が使える。
- エディタと統合ターミナルの両方で試す。
- 新しいタブでプレビューを開いても同じIMEが使える。

Windows IMEはWindows側で動くブラウザで確認する。
WSLg上のLinuxブラウザで代替したことにはしない。
